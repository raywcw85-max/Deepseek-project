# Deepseek-project

一個零依賴、單一檔案的 HTML5 貪食蛇遊戲。

## 遊戲特色

- 20 × 20 棋盤，Canvas 繪製，支援高解析度螢幕
- 分數、最高分（localStorage 自動保存）、蛇身長度即時顯示
- 每吃 5 個果實會出現限時的黃金果實（+30 分），並隨之加速
- 鍵盤、滑動手勢、螢幕虛擬方向鍵三種操作方式
- 暫停／繼續、重新開始、音效開關（WebAudio 即時合成）
- 粒子特效、蛇身漸層、果實呼吸光暈、撞牆震動回饋
- 支援手機與桌面，尊重 `prefers-reduced-motion`

## 開始遊玩

直接用瀏覽器開啟 `index.html` 即可，不需要安裝任何套件或建置。

若想透過本機伺服器開啟：

```bash
python3 -m http.server 8000
# 瀏覽器打開 http://localhost:8000
```

## 操作方式

| 操作 | 按鍵／動作 |
| --- | --- |
| 移動 | 方向鍵 或 `W` `A` `S` `D` |
| 開始／暫停 | `Space`（開始、暫停、繼續） |
| 重新開始 | `R`（隨時）、`Enter`（開始前或結束後重玩；暫停時繼續），或點擊「重新開始」按鈕 |
| 音效開關 | `M` 或點擊音效按鈕 |
| 手機操作 | 在畫面上滑動轉向、輕觸畫面暫停，或使用下方虛擬方向鍵 |

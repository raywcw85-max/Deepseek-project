# Deepseek-project

澳門松山健康徑 3D 跑步模擬器：以 Three.js 製作的環山跑步遊戲。

## 遊戲特色

- 全長 1,708 米的松山環山跑道（由真實 GPX 軌跡正規化），含高低起伏與彎道
- 第三人稱跟隨鏡頭，可切換標準、遠景、貼地三種視角
- 手動轉向、衝刺與體力系統；上坡減速、落坡加速
- 以 Three.js 原生幾何體組裝的東望洋燈塔、黃白相間聖母雪地殿、360° 旋轉探照燈
- Mixamo `runner.fbx` 跑手模型、`AnimationMixer` 循環跑步動畫，衝刺時動畫加速
- 數百棵路樹與路燈使用 `InstancedMesh`，大幅減少 draw calls
- 程序化 Canvas 瀝青／紅褐地磚貼圖、凹凸貼圖、灰混凝土路壆、墨綠鐵欄與噴漆里程
- 多層低多邊形樹冠，混合深綠、翠綠與黃綠色，並投射柔和樹蔭
- PCFSoft 柔和陰影、ACES Filmic Tone Mapping、漸層天空、距離霧與低多邊形澳門天際線
- 早晨、黃昏、夜晚三段日夜切換；夜晚會亮起路燈、星空與增強的燈塔射燈
- 沿途松山防空洞、涼亭、綠色欄杆與里數標記
- 15 位隨機分佈的街坊 NPC：內圈慢行、兩人並排、倒後行；玩家靠近 10 米會顯示澳門地道對白
- 撞到街坊會減速並扣體力；藍色水樽可補給體力
- Web Audio API 動態合成腳步聲、衝刺滑音、松山環境音、補水提示音與輕快 BGM
- 圈速計時、最佳成績、即時 HUD 與環山小地圖
- 鍵盤與手機虛擬搖桿／按鈕操作

## 開始遊玩

本專案使用 ES Modules，需透過 HTTP 伺服器開啟（不可直接以 `file://` 開啟）：

```bash
python3 -m http.server 8000
# 瀏覽器打開 http://localhost:8000/index.html
```

Three.js、FBXLoader、fflate 與 Tailwind CSS 由 CDN 載入，首次開啟需連網。

## GPX 跑道資料

專案根目錄的 `20261022102151.gpx` 與 `20261022103857.gpx` 是同一條松山環山徑的連續紀錄。`track.js` 會取 A 段第 0–583 點組成完整一圈（1,708 公尺），B 段則用作同路線交叉驗證。GPX 的 `lat`、`lon`、`ele` 已經過平滑、每約 8 公尺取樣，並正規化為 Three.js 座標：

- 以跑道包圍盒中心為原點，向東為 `+X`、向上為 `+Y`、向北為 `-Z`
- `WORLD_SCALE = 0.4`（1 個 Three.js 單位 = 2.5 公尺）
- 海拔再放大 3 倍，保留松山 46–49 公尺的上下坡效果

## 音效

`audio.js` 使用瀏覽器原生 Web Audio API 即時合成，不需要任何音效檔案：

- 低頻白雜訊腳步聲，速度越快步頻越密
- 衝刺時播放上升頻率滑音
- 松山微風、樹葉聲與隨機蟬鳴／鳥叫環境音
- 飲水補給的雙音階提示音
- 124 BPM、C 大調五聲音階的輕快琶音 BGM（正弦波／三角波合成）
- 點擊「立即起跑」時解鎖 AudioContext 並自動啟動環境音與 BGM
- 右下角「🎵 音樂」可獨立開關 BGM；「🔊 音效」控制全部音效
- 如根目錄存在 `bgm.mp3`，會自動優先播放該 MP3；否則使用程序合成 BGM

## Mixamo 跑手

`player.js` 會以 `FBXLoader` 載入根目錄的 `runner.fbx`，模型縮放為 `0.01`、腳底對齊跑道，並以 `AnimationMixer` 循環播放模型內建的 Running 動作。正常跑步時 `timeScale = 1.0`，按住衝刺時會平滑加速至 `1.6`。若 FBX 載入失敗，會自動保留方塊跑手作備援。

## 操作方式

| 操作 | 按鍵／動作 |
| --- | --- |
| 轉向 | `A` / `D`、左右方向鍵，或左下角虛擬搖桿 |
| 衝刺 | 按住 `Space` / `Shift`，或右下角「衝刺加速」按鈕 |
| 切換視角 | 點擊「📷 視角切換」 |
| 切換時段 | 點擊右下角「🌅 早晨」按鈕，依序切換早晨／黃昏／夜晚 |
| 音效開關 | 點擊「🔊 音效」切換全部音效 |
| 音樂開關 | 點擊「🎵 音樂」獨立開關背景音樂 |
| 玩法說明 | 點擊「💡 玩法說明」 |

## 專案結構

```
index.html   # 頁面結構與 UI
style.css    # 自訂樣式（Tailwind 之外的玻璃面板、搖桿等）
main.js      # Three.js 場景、日夜燈光、鏡頭、HUD、小地圖與遊戲循環
track.js     # GPX 正規化、跑道樣條、InstancedMesh 樹木／路燈、地標與松山環境
player.js    # FBX 跑手載入、AnimationMixer、操控、物理、碰撞與賽道事件
audio.js     # Web Audio API 動態合成音效與 BGM 引擎
bgm.mp3      # 選用：放入後會優先取代程序合成 BGM
runner.fbx   # Mixamo 跑步模型與 Running 動畫
20261022102151.gpx  # 松山環山徑 GPX（去程／第一圈）
20261022103857.gpx  # 松山環山徑 GPX（回程／驗證）
snake.html   # 舊版貪食蛇遊戲（保留備份）
README.md
```
